Guide to Embedding Media
in ACP's HTML5 Interactives

Prompting ACP to Add Media HTML5 ZIP-Media Compiler *Guide to using AI Chatbot

In SLS Authoring Copilot (ACP), write your prompt recipe for HTML5 interactive generation.

You may want to copy and paste teacher-created content and/or the codebase from an existing interactive (index.html, style.css, and script.js) into ACP's Knowledge Base to guide ACP in generating the interactive you want.

In your ACP prompt, clearly specify the exact names of all media files to be added. Filenames are case-sensitive. For example:

  • image.png
  • VideoClip.mp4
  • diagram01.jpg

You can refer again to the prompts in the Prompting ACP to Add Media guide.

Ensure filenames in ACP exactly match the real media filenames, including capitalization.

Let ACP generate your interactive, then iterate and refine your prompt until all required media placeholders are correctly included. When the ACP output meets your expectations, click Add to confirm the final version.

Download the Interactive ZIP file from the bottom-right download button.

The ZIP file should contain these separate files:

  • index.html
  • script.js
  • style.css

Next step:

Option 1: Manual Method

  • Unzip the ZIP file
  • Add your media files to the main folder
  • Test the interactive in your local browser to make sure your media files display and play correctly
  • Select all files and compress them into a new ZIP file

Proceed to Step 8 to upload the ZIP into the SLS component.

Option 2: If you are unsure how to unzip and zip files with the media files, or whether the media filenames are properly referenced to the codebase, follow Steps 5 to 7 and use the HTML5 ZIP-Media Compiler to assist you.

Upload the full ZIP file into the HTML5 ZIP-Media Compiler.

Upload all media files referenced in your HTML5 files (images, audio, and video) to the HTML5 ZIP-Media Compiler.

Review and fix any media path or filename errors so they align with ACP placeholder references and use main folder filenames only (for example, image.jpg).

In the HTML5 ZIP-Media Compiler, click Generate ZIP to download a new ZIP file containing index.html, style.css, script.js, and all uploaded media files in the main folder.

(You may unzip the ZIP file and test the interactive in your local browser to make sure your media files display and play correctly.)

Upload the new ZIP file into SLS's Text Media Component. Use the Add Media icon 📎 and select Upload File. Then open the interactive inside SLS, try it out, and verify that all media were added correctly.
