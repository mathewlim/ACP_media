Basic Prompts for Adding Media Placeholders

Instruction: Click "Copy Prompt," paste it into ACP (or any LLM), then refine or modify the prompt.

1. Adding Image

Add an image placeholder to this interactive. Place the image in the main folder. Place all images in the main folder (same folder as index.html). Use this exact filename (case-sensitive):

heroimage.jpg

Create a visible placeholder so I can add the actual image later.

What this means: This prompt asks ACP to prepare a spot in your web page where a picture will go. You'll see a gray box or temporary image showing where your real picture will appear. The main folder is where your media files are stored for this setup.

2. Adding Sound Effect

Add a sound effect to this interactive. Store the audio in the main folder (same folder as index.html). Use this exact filename (case-sensitive):

clicksound.mp3

The sound should trigger when users interact with the element (e.g., clicking a button).

What this means: This prompt adds a sound effect that will play when users interact with an existing element on your page (like clicking a button or card). An interactive refers to any element that responds to user actions - buttons, games, quizzes, or animations controlled by JavaScript code. The sound will be connected to the element in the code. Once you add your audio file with the exact filename, it will play automatically when the element is clicked or triggered.

3. Adding Video

Add a video placeholder to this interactive. Place the video in the main folder (same folder as index.html). Use this exact filename (case-sensitive):

introvideo.mp4

Create a visible placeholder so I can add the actual video later.

What this means: This creates a video player area on your page. You'll see a rectangular box (often gray or with a play icon) showing where your video will appear. Once you add your actual video file with the exact name specified, it will automatically load into this space.

4. Adding Background Audio

Add looping background music to this interactive.

The audio file should be named backgroundmusic.mp3 (using exact lowercase spelling) and placed in the main folder (same folder as index.html).

The music should start playing when the user clicks the first icon.

Include visible audio controls that allow the user to play or pause the music, mute or unmute the audio, and adjust the volume level.

What this means: This sets up music that plays continuously in the background while users view your page. "Loop" means the music will restart automatically when it ends. The interactive will include a volume control (like a slider or mute button) so you can adjust the music volume directly within the interactive. Once you add your audio file with the exact filename, it will play automatically.

Important Notes for All Prompts

Case-sensitive filenames: When you upload your files, the names must match EXACTLY - including capital and lowercase letters. For example, backgroundmusic.mp3 is different from BackgroundMusic.mp3. If the names don't match perfectly, your media won't appear when uploaded to SLS.

The main folder: Keep all media files (images, sounds, videos) in the same root folder as your index.html, style.css, and script.js files.
