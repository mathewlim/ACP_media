3. Add media and create your ZIP

  1. Open the compiler and upload the chatbot's three code files or project ZIP. If it could only provide code, paste each block into its matching editor: index.html, style.css or script.js, without the Markdown backticks.
  2. Upload your media files with the exact names used in the code. Fix any filename or path errors.
  3. Click Generate ZIP, then upload it in SLS under Text/Media → File from Device.
